# map3d — working guide

This is an existing browser-only mapping application, not the ecportal/GAS system described in some shared templates. Read `README.md`, `SCOPE.md` and `docs/APP_AUDIT.md` before broad changes. The reference policy repository is https://github.com/playerkousas-rgb/readme; apply its relevant lightweight/safety/provenance/version checks without importing unrelated account/admin infrastructure.

- React/Vite/Three.js/Leaflet. Hosting serves static `dist/`; public data requests go directly from the browser to providers.
- Geometry units: metric UTM in orienteering; compressed horizontal display in legacy map mode; millimetres in the GPX miniature. CAD export must preserve the explicit conversion metadata. See `SCOPE.md`.
- Add GIS sources through `src/config/dataSources.ts`. Do not label a download page as WMS, feed a Shapefile ZIP to GeoJSON, invent a layer identifier, embed remote HTML, or bundle large source datasets.
- Preserve provider attribution and MIT notices. State what source was inspected and distinguish implementation from documented behaviour and unverified assumptions.
- Keep course drafts/import/export and read-only player mode compatible. Do not introduce authentication, private APIs, platform proxies, external storage or deployment changes without an explicit product need.
- Runtime dependencies must be necessary. Test/browser binaries, downloaded GIS fixtures and screenshots stay outside Git. The existing repository/bundle budgets must pass; do not weaken a guard just to make a build green.
- Before delivery: `npm run check` and `git diff --check`. UI work: use `npm run verify:ui:isolated` with installed Chromium (or an existing dev server plus `npm run verify:ui`), inspect 390/768/1440 screenshots, and report mocked/live boundaries. See `docs/APP_AUDIT.md` for browser setup and current gaps.
- Release changes: keep package/lock, `src/config/app.ts`, HTML, manifest and versioned icon paths aligned; `npm run verify:release` enforces this. Update `CHANGELOG.md` and the as-built report.
- Never claim deployment, supplier uptime, real-device behaviour, security certification or complete LoD2 from passing local tests alone.

- Dependency repairs: run `npm run audit:deps` and report production/full-graph counts separately. Development-only moderate minimatch reports are documented in `docs/dependency-security.md`; do not hide them or force an incompatible major override. CI also runs the isolated browser suite and uploads screenshots.

- Local GIS files remain ephemeral, bounded and geometry-only; never imply raw WorldPop TIFF or HydroRIVERS ZIP support. See `docs/local-data-and-sharing.md`. Player links must strip planner notes, bound decompression, react to same-page hashes and preserve the saved draft/area. Do not regress upward terrain winding or ground picking; browser tests exercise a real tap, backup, clipboard sharing and player exit.
