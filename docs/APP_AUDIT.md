## Reference and scope

Read `playerkousas-rgb/readme` at revision [`206cb0c24d028651d804ec19942dc9791b499fdd`](https://github.com/playerkousas-rgb/readme/tree/206cb0c24d028651d804ec19942dc9791b499fdd): README, AGENTS, PLAYBOOK, quickcard, repo-health guide, system-basics/consistency/icon guidance and the promoted design-review text. It is guidance, not map3d application source. Its ecportal/GAS/admin examples were deliberately not copied into this browser-only application.

map3d has local course data but no accounts or private backend. Applicable priorities are lightweight delivery, registry-driven settings, input validation, visible failure/retry, export/backup, provenance, copyright and consistent release metadata. An authentication system, hidden administrator, Supabase migration and platform API proxy would change the product boundary and were not introduced.
