# 使用指南 · map3d v0.1.0

## 地圖 → 3D 建築

1. 選「地圖 → 3D 建築」，搜尋地點。
2. 點「選取範圍」，在地圖上拖出範圍，再按下一步取得建築。
3. 如需參考資料，展開地圖下方「GIS 資料來源」：底圖只能選一項，Natural Earth 圖層可獨立開關。載入失敗可按重試或換回 OpenStreetMap。
4. 完成載入後進入 3D，點建築查看 OSM 資料；有 `roof:shape=gabled` 的建築會顯示雙坡屋頂；`skillion` 使用有向單坡。方向可為數字方位或16個羅盤方向，代表下坡方向；正起伏但缺少有效方向會暫以總高度平頂顯示，載入卡及定向場景設定會顯示獨立提示數量。
   - `roof:shape=hipped`（四坡）在投影後四個真角、無洞矩形（可有有界近共線邊上節點，原座標保留）且有 `roof:height`／`roof:levels` 時產生兩端收短屋脊及四坡；沿長邊或across、有效且與邊對齊的direction可用。亦支援 `roof:ridge:direction`（沿屋脊方位），優先序為有效下坡direction→ridge direction→orientation；壞的正在使用方向不偷偷轉用較低標籤。[方向規則與投影限制](hipped-ridge-direction.md)。非矩形／中庭／angle-only／缺rise／不支援方向以總高度平頂並顯示獨立數量，顯式零不誤報。投影誤差可能使兩模式fallback數量不同，並非所有實際矩形都支援。[來源與限制](hipped-roofs.md)。直邊多插入口等節點不再直接退平頂；預設按完整邊長選軸，不按分段長度猜，凹口／曲邊／折返仍不支援。[節點與底蓋驗證](hipped-collinear-nodes.md)。
   - `roof:shape=pyramidal`（金字塔）在無洞凸外框且有 `roof:height`／`roof:levels` 時，以面積重心作尖頂。凹外框／中庭／只有 `roof:angle` 或缺rise時保留輪廓、以總高度平頂顯示，載入與場景設定有獨立提示；顯式零不誤報。不是完整屋頂／LoD2。[支援範圍](pyramidal-roofs.md)。
   - `min_height` 可保留架空底部（含公尺／英尺／顯式0），優先於 `building:min_level`；後者正值需要有效總層數，按扣除屋頂後的每層高度計算。不會把屋頂再往上搬；無效高度區間會顯示略過數量，不填到地面。坡地仍用最小地面datum，非每點淨空／支柱模型。[範圍與驗證](building-elevation.md)。
   - 閉合且支援的 OSM multipolygon 中庭與內島會保留各自的屋頂／內牆洞口；角色必須outer／inner交替，nested OSM relation不支援。缺片、自交、相觸／角色無效或超過拓撲安全預算（2,048來源座標／65環）的建築會顯示略過數量，不會自行封口填平。building parts／完整屋頂仍不支援；顯式零屋頂高度／角度會保持平頂。[單坡限制](skillion-roofs.md)。[詳細限制](building-islands.md)。
5. 開「匯出」選格式。DXF 為 R2010／3DFACE，CAD Z 軸向上；本輪已修正writer原始owner／handle引用，並以獨立ezdxf檢查63份真正瀏覽器下載（含地形備援／參考平面與場景內復原），仍未通過桌面CAD廠商驗收（[驗證與限制](cad-conformance.md)）；它是表面網格，不是 BIM 物件或保證封閉的 CAD 實體。

**注意：**Natural Earth 是全球概覽資料，在小範圍香港街道圖可能看不到任何線。NASA 選項是標示日期的歷史影像，不是即時衛星圖。WorldPop／HydroRIVERS 只提供官方下載／條款入口，不是可直接載入的圖層。

## 本地參考圖層

在「GIS 資料來源」底部選來源標記，再匯入已裁切、轉為 **WGS84 [經度, 緯度] GeoJSON** 的檔案（頂層FeatureCollection，最多 2 MB／10,000 圖徵／150,000 座標）。其中可混合點、線、面、Multi*與巢狀GeometryCollection，最多8層集合、整檔20,000 Geometry；保留Polygon洞口。只有空集合／沒有可畫座標的檔案不會替換原圖層，不直接接受bare GeometryCollection根節點（[完整限制](map-footer-layout.md)）。點「縮放至本地圖層」查看位置；移除後可重選檔。比例尺現在放在地圖右下方、完整來源註記之上；選取提示／即時尺寸放在地圖下方，短螢幕可捲動閱讀，不會再浮在credit上。錯誤檔不會取代原有有效圖層，檔案不會上傳。

這是暫存的 2D 幾何參考，不會加入課程備份或 3D 匯出；切換模式／還原範圍可能清除，請保留原檔。**不接受原始 TIFF、ZIP、Shapefile，也不計算人口數值或色階。** HydroRIVERS 須先在外部 GIS 裁切、轉換；WorldPop 的 raster 分析亦須另外處理。詳見 [前處理與限制](local-data-and-sharing.md)。

## GPX → 列印模型

1. 選「GPX → 3D 列印模型」，匯入 GPX 檔。
2. 檢查點數、高程範圍及路線是否合理；沒有高程的檔案可使用既有補高程功能。
3. 調整誇張比例、軌跡寬度及底板厚度。
4. 列印可選 STL；CAD 可選 DXF。GPX 是縮小的毫米模型，DXF 會換算為米，並非實際地理全尺寸。

## 3D 城市定向

1. 選「3D 定向」，圈定範圍，再取得建築、道路及地形；失敗項目可個別重試。地形任何格點無效／缺值時整批改用備援；兩個來源都失敗會明示「平坦參考地面」，不是成功取得0米高程。真0米及負海拔仍為有效資料；可重試或不使用地形繼續，匯出亦保持該明示平面。中庭保留及不支援輪廓的略過警告與地圖模式一致，場景設定亦可查看數量。
2. 進入場景，放置起點、檢查點及終點，填寫代碼／線索。
3. 在場景設定切換底圖、10 米等高線、地形陰影及誇張比例。資料不可用或部分區塊失敗時，可直接按「重試 建築物／道路／地形」，不必退出3D；只替換該層，不改控制點、私人備註或其他圖層。載入中重複按不會另開請求；該層可能暫時清空／地形暫平，完成後回填。等高線由現有粗 DEM 插值，不能當測量成果。
4. 匯出課程 JSON 作備份；分享玩家連結可開唯讀檢視，不會覆蓋對方自己的草稿。**JSON 備份含規劃者備註，請勿直接當玩家公開檔傳送。** 新連結排除私人備註；舊連結可能已包含備註且不能撤回。
   - 編輯／備份／匯入共用上限：完整 JSON 備份 1,000,000 UTF-8 bytes／2,000 點（含起終點）／每文字欄 4,000 UTF-16 單位（部分 emoji 計兩個）。無效或超限不會偷偷刪點、截字；手動修改被拒時保留原課程與 undo／redo。
   - 已開啟 APP 也能跟隨 `#play` 連結；離開玩家模式會還原原草稿及範圍。過大／錯誤連結會顯示失敗。
   - 手機面板頂部握把可拖曳、點擊或用鍵盤操作：↑/↓ 調整一級，Home 收起，End 展開；停靠高度會依螢幕空間收斂。短高度時標頭也會進入捲動區；短橫向改用可捲動側欄。
   - 點場景頂端的相機圖示開「相機控制」：重設視角／俯視／斜視／放大／縮小，選完即關閉。鍵盤可開啟並選操作，Escape 關閉並回到開啟按鈕；點外部也能關閉。這不是模態視窗，不會困住 Tab。缺少 Popover API 時使用同一組操作的降級介面。
   - 展開面板時保留控制與來源註記空間；空間不足會隱藏非必要操作提示，不隱藏地圖來源。超長名稱只在提示／玩家標頭限制顯示兩行，JSON／原資料不會被截短。
5. 模型可下載 GLB 或 DXF。GIS 選圖頁的參考圖層不會變成模型匯出內容。

## 草稿儲存失敗／無法讀取

- 如顯示「草稿未能儲存」，變更只暫存在目前分頁。請先按「下載目前 JSON 備份」，**不要直接關閉或重新整理**；瀏覽器允許儲存後可按「重試儲存」。成功只代表瀏覽器接受寫入，不是永久備份。
- 同一頁開啟玩家連結再返回，會帶回尚未儲存的私人課程、範圍及場景設定；但重新整理／關閉頁面仍可能遺失未儲存修改。
- 如顯示原有草稿無法讀取，APP 不會自動用空白資料覆蓋它。先下載「原始資料」留作修復；只有按「取代原始草稿…」並確認，才會以目前草稿取代。原始檔可能本來就不是有效 JSON，也可能包含私人備註，請勿公開。
- 已成功儲存的空課程仍會保留名稱／活動資料；成功儲存的範圍會在重新整理後還原。帶本 APP 標記的空課程 JSON 備份亦可匯入。
- 本輪已對齊正常編輯與備份限制。靠近 1 MB 時備份可能不再縮排，這是省掉空白而非刪資料；若連 compact JSON 也超限，修改會被拒並顯示原因。明確清空的代碼／活動欄位可原樣往返。詳見 [限制契約](course-budgets.md)。已有需確認的多分頁衝突處理，但沒有自動合併／雲端同步。

## 多個分頁同時編輯

- 有 Web Locks 的瀏覽器會序列化同源草稿寫入，並在寫入鎖內比較版本。等候時顯示「尚未確認完成」，仍可下載目前記憶體備份；不可把等候當作已儲存。
- 出現「另一分頁已修改或刪除」時，此頁資料仍在，但已暫停自動儲存。先下載此頁 JSON 與已存版本原文，再選：
  - **載入已存版本…**：確認後放棄此頁修改，載入已存課程／場景／範圍並清空過時的 undo／redo；若已刪除則載入空課程。已存版本損壞時不會清空此頁資料。
  - **以此頁取代已存版本…**：確認後才取代；若等候鎖期間另一分頁又更新，會再次要求選擇，不用舊確認覆蓋新資料。
- 玩家模式不寫入公開課程，也不自動載入其他分頁草稿；返回後才處理私人草稿的未儲存／衝突提示。
- 有未儲存資料時通常會收到瀏覽器原生離頁提醒；**行動裝置可能不觸發，請先下載備份**。
- 無 Web Locks 的瀏覽器會明確提示只開一個編輯分頁。降級的「先比較再寫入」不是原子操作，不能保證並行安全；舊版 APP 或其他繞過鎖的程式也不受合作式鎖約束。
- 選圖地圖縮放改為即時完成，不使用 CSS 縮放動畫，以避免玩家切換／重掛載時舊動畫回呼存取已移除的地圖。

詳見 [多分頁／地圖生命週期契約](draft-concurrency.md)。

詳細的已完成與待辦請看 [工作進度](STATUS.md)。

## 匯出提示／安裝

- 匯出視窗可按右上角「×」、Escape 或視窗外關閉；關閉後焦點回到原來的匯出按鈕。鍵盤 Tab／Shift+Tab 只在視窗內切換，底下的地圖／3D 操作暫停接收操作。

- 「正在準備」期間不用連按。失敗時先確認場景已載入，再重試或縮小範圍／換格式。
- 「已交給瀏覽器下載」不代表檔案已存好；如沒有檔案，檢查瀏覽器下載權限及下載列表。
- 支援的瀏覽器可使用「加入主畫面」。圖標／manifest 已配置，但**沒有離線地圖保證**；地圖和公開資料仍需要網絡。

所有地圖、高程和推算高度僅供參考。活動前必須核對官方地圖、天氣及實地情況。

## English quick start

Choose a mode → select an area or import GPX → check loading status and data limits → open the 3D view → export. The GIS panel provides 2D reference layers only. Bulk WorldPop/HydroRIVERS sources require external preprocessing. Export messages report browser download requests, not confirmed file saves. Back up courses as JSON. Never use interpolated terrain or estimated building heights as authoritative navigation/survey data.


## 模型匯出範圍

- GLB／glTF／OBJ／STL／DXF 共用 `Object3D.visible` 階層政策；隱藏物件或隱藏父群組的子物件不輸出。建築圖層重新開啟後，下一次匯出才重新包含它。
- **關閉「地形」只是壓平地面，不會移除地面**；平面地面仍在場景及模型檔。Legacy map的選區框／底板、GPX miniature原有底座與單位政策保留。
- 匯出已開啟且標記為可匯出的模型，不是整個螢幕：DXF不包含地圖影像、文字點號或2D GIS疊圖／材質顏色。GLB／glTF、OBJ、STL各有不同格式能力；不保證逐像素相同。
- 不以相機看不到、被遮擋或材質透明就自動刪掉幾何。匯出範圍與限制見 [來源／驗證](export-visibility.md)。只有隱藏網格或沒有模型的輸入會報錯，不以空檔假裝成功。


## 部署與安全政策提示

本輪已配置production Content Security Policy，正式主機仍需送出對應HTTP header；本地built-production測試不等於已部署。腳本只容許同源，GIS仍直接連到已列入的公開資料origins，沒有新增代理或登入。正常的GPX／課程／模型下載不需要容許unsafe-eval或blob腳本。

若自行新增資料來源／瓦片域名或換靜態主機，請維護者依 [CSP政策與驗證](content-security-policy.md) 審查response header與provider清單，再重跑production gate。資料失敗先查看狀態／重試／範圍與供應商可用性，不要直接關閉CSP或開放所有HTTPS。回報問題不需要交出私人課程／player分享連結。這不是完整帳號權限、離線或資料加密功能。


## GPX 模型設定與小螢幕

- 操作提示現在放在模型設定卡內，手機也能閱讀；卡片內容多時，在卡片內捲動，不用放大或左右拖頁。
- 三個滑桿有名稱與單位，可Tab進入、用方向鍵調整；STL匯出按鈕在卡片下方。底部的「匯出」仍可選其他支援格式。
- 設定卡是浮層，展開時可能蓋住模型；按「收合設定」可騰出觀看／拖動模型的空間，再按「展開設定」繼續調整，參數不會因此重設。鍵盤Enter／Space同樣可操作。成功匯入另一個GPX時會重新展開。
- 長路線名稱會換行，沒有改短檔案中的名稱。無海拔資料時仍需自行核對或使用原有補值功能；本輪layout測試不代表補值供應商live覆蓋已驗收。


## GPX 匯入範圍與海拔

- 請用非空的**UTF-8 GPX，最多10MB／50,000原始點**，單一連續track segment或單一路線。多條軌跡／多段／route混合請先在GIS工具拆分，不會自動連接GPS中斷缺口。Waypoint-only不是軌跡。
- 非法／越界／非有限座標、非法海拔、沒有水平範圍或跨換日線會拒絕整檔，不會略過壞點接出捷徑；模型海拔限-12,000～10,000m。修正後可以選同一個檔案重試，錯誤會跟隨語言切換。
- 超過3,000點會保留首尾抽稀，畫面顯示原始→模型點數；距離／爬升是模型近似值，不作原始里程保證。
- 全零／恆定海拔是合法資料，不等於缺資料；部分點缺海拔時整個模型先平放並提示，不製造假的海平面陡降。非法ele不會當作缺值自動修好。
- 主動「用地形資料自動補回海拔」會把抽樣座標送至既有公開API，補值取代所有模型點的海拔；請評估行蹤私隱。兩個服務都無資料／失敗時會保留原模型，不以0m假成功。
- 新選檔或切換模式會取消舊讀取，舊檔不能稍後突然打開模型。檔案本體仍在瀏覽器本地處理；這不是多軌／完整GPX schema／大型streaming XML或live DEM覆蓋保證。詳見 [匯入安全與限制](gpx-import-safety.md)。
